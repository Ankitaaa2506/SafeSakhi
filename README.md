# 🛡️ Safe Sakhi

> **A modern women's safety platform that provides instant emergency assistance, AI-powered guidance, live location sharing, nearby safe places, and trusted contact alerts.**

---

## ✨ Features

- 🚨 One-Tap Emergency SOS
- 📍 Live Location Sharing
- 🤖 AI Safety Assistant
- 🏥 Nearby Hospitals & Police Stations
- 🧭 Safe Route Assistance
- 📞 Emergency Contacts
- 🗺️ Interactive Maps
- 🔐 Secure Firebase Authentication
- ☁️ Cloud Firestore Integration

# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/yourusername/safe-sakhi.git
```

### Install Packages

```bash
flutter pub get
```

### Run

```bash
flutter run
```
